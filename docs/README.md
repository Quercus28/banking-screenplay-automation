Documentación del punto 2 del Taller 2 (Calidad de Software 2026-2, UdeA): exploración manual de la aplicación GlobalSQA Banking Project para identificar sus flujos funcionales antes de automatizar con Screenplay y Serenity BDD.

## Convenciones

- `EXP-NNN`: escenario explorado. `HAL-NN`: hallazgo.
- Estados: Conforme, No conforme, Bloqueado, No ejecutado.
- Los nombres de archivo de las capturas inician con el ID del caso que evidencian; el mismo nombre se usa en originales y anotadas.
